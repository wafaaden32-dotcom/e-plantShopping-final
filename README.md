# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery Shopping Application

## Project Description
Paradise Nursery is a React-based shopping application for browsing and purchasing houseplants.

The application allows users to:
- Browse different categories of houseplants.
- View plant names, images, descriptions, and prices.
- Add plants to the shopping cart.
- Increase or decrease plant quantities.
- Remove plants from the cart.
- View the total quantity and total cost of items in the cart.
- Continue shopping or proceed to checkout.

## Technologies Used
- React
- Redux Toolkit
- React-Redux
- JavaScript
- CSS
- Vite

## Main Features
### Landing Page
The landing page displays the company name, a company description, a background image, and a "Get Started" button.

### Product Listing
The product page displays houseplants organized into different categories. Users can add plants to the cart and see the cart quantity update.

### Shopping Cart
The cart displays each selected plant, its image, name, unit price, quantity, and total cost. Users can increase or decrease quantities, delete items, continue shopping, or use the checkout button.

## Company
Paradise Nursery is a plant nursery focused on bringing nature closer to customers by providing a variety of high-quality plants for homes and offices.
